# C++ Arrays and Strings Practice Tasks

Follow each requirement exactly. Use arrays or strings as requested.

1. Store weekly temperatures `{30, 32, 29, 35, 31, 33, 34}` in an integer array. Find and print the highest temperature.
   Example output:
   ```text
   Highest temperature = 35
   ```

2. Store marks `{45, 78, 32, 90, 55}` in an integer array. Count and print how many marks are greater than or equal to `50`.
   Example output:
   ```text
   Passed students = 3
   ```

3. Store the 3x3 matrix `{{1,2,3},{4,5,6},{7,8,9}}`. Print only the main diagonal values: `1 5 9`.
   Example output:
   ```text
   1 5 9
   ```

4. Read a full name using `getline()`. Print the number of characters using `.length()` with the label `Characters =`.
   Example input:
   ```text
   Anu Priya
   ```
   Example output:
   ```text
   Characters = 9
   ```

5. Store `word = "hello"`. Change only the first character to uppercase `H` using index `0`, then print the word.
   Example output:
   ```text
   Hello
   ```

6. Store `word = "student"`. Use a range-based loop and `toupper()` to convert every character to uppercase.
   Example output:
   ```text
   STUDENT
   ```
