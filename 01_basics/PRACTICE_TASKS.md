# Basic C++ Practice Tasks

Follow each requirement exactly. Use clear output labels so the answer can be checked easily.

1. Create four variables: `name = "Kiran"`, `rollNumber = 24`, `department = "Computer Science"`, and `city = "Chennai"`. Print them as a student ID card with one value per line.
   Example output:
   ```text
   Student ID Card
   Name: Kiran
   Roll No: 24
   Department: Computer Science
   City: Chennai
   ```

2. Create variables for `product = "Notebook"`, `price = 45.50`, `quantity = 3`, and `available = true`. Print the product name, total bill amount, and availability status.
   Example output:
   ```text
   Product: Notebook
   Total: 136.5
   Available: 1
   ```

3. Read one full sentence from the user using `getline(cin, sentence)`. Print the output exactly with the label `Sentence:`.
   Example input:
   ```text
   I want to learn C++
   ```
   Example output:
   ```text
   Sentence: I want to learn C++
   ```

4. Use `const float RATE = 5.0f`. Store `principal = 10000` and `time = 2`, calculate simple interest, and print it with the label `Simple Interest =`.
   Example output:
   ```text
   Simple Interest = 1000
   ```

5. Print a three-row timetable using `\t` for spacing and `\n` for new lines. The rows must be `Mon C++`, `Tue Maths`, and `Wed English`.
   Example output:
   ```text
   Day     Subject
   Mon     C++
   Tue     Maths
   Wed     English
   ```

6. Write a program without `using namespace std`. Read one word into a `std::string name` and print `Hello <name>` using `std::cout`.
   Example input:
   ```text
   Anu
   ```
   Example output:
   ```text
   Hello Anu
   ```
