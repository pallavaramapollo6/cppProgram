# C++ Structures and Pointers Practice Tasks

Follow each requirement exactly. Use the requested feature in each task.

1. Create a `Book` structure with `title`, `author`, and `price`. Store `C++ Basics`, `Ravi`, and `250.5`, then print all fields.
   Example output:
   ```text
   C++ Basics
   Ravi
   250.5
   ```

2. Create an `Employee` structure with `name` and `salary`. Store exactly two employees: `Anu 20000` and `Kiran 25000`, then print both.
   Example output:
   ```text
   Anu 20000
   Kiran 25000
   ```

3. Create an enum `OrderStatus` with values `PLACED = 1`, `SHIPPED = 2`, and `DELIVERED = 3`. Store `SHIPPED` and print its numeric value.
   Example output:
   ```text
   Status code = 2
   ```

4. Store `price = 100.0f`. Use a pointer to change it to `120.0f`, then print the changed price.
   Example output:
   ```text
   Price = 120
   ```

5. Store `a = 10` and `b = 20`. Use two pointers and a temporary variable to swap the values, then print both.
   Example output:
   ```text
   20 10
   ```

6. Store `salary = 30000`. Use a pointer and pointer-to-pointer to print the salary using `**ptr2`.
   Example output:
   ```text
   Salary = 30000
   ```
