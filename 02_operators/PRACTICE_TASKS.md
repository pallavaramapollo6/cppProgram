# C++ Operators Practice Tasks

Follow each requirement exactly. Do not change the given sample values unless the question asks for input.

1. Store marks `80`, `75`, and `90` in three integer variables. Calculate and print `Total =` and `Average =`. Average must show decimal calculation.
   Example output:
   ```text
   Total = 245
   Average = 81.6667
   ```

2. Store `bill = 1500`. Use a relational operator to print whether the customer gets a discount. Discount is allowed only when bill is greater than or equal to `1000`.
   Example output:
   ```text
   Discount available: 1
   ```

3. Store `hasUsername = true` and `hasPassword = true`. Use logical AND to print whether login is allowed.
   Example output:
   ```text
   Can login: 1
   ```

4. Store `wallet = 500`. Add `200` using `+=`, subtract `150` using `-=`, and print the final wallet balance.
   Example output:
   ```text
   Wallet balance = 550
   ```

5. Store `lightOn = false`. Use the logical NOT operator to toggle it once, then print the new value.
   Example output:
   ```text
   Light on: 1
   ```

6. Store `total = 7` and `count = 2`. Use `static_cast<double>` so the division result prints as `3.5`.
   Example output:
   ```text
   Result = 3.5
   ```
