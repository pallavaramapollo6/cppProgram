# C++ Functions Practice Tasks

Follow each requirement exactly. The function name and parameter list must match the task.

1. Create a `void banner()` function with no parameters. It must print `Welcome to C++ Programming`. Call it from `main()`.
   Example output:
   ```text
   Welcome to C++ Programming
   ```

2. Create `int cube(int number)`. Return the cube of `number`. In `main()`, call it with `3` and print the result.
   Example output:
   ```text
   Cube = 27
   ```

3. Create `int area(int length, int width)`. Return rectangle area. In `main()`, call it with `5` and `4`.
   Example output:
   ```text
   Area = 20
   ```

4. Create `void swapNumbers(int &a, int &b)`. Use references to swap `x = 10` and `y = 20`, then print both values.
   Example output:
   ```text
   20 10
   ```

5. Overload `area()`: `area(int side)` for square and `area(int length, int width)` for rectangle. Print results for side `5` and rectangle `5 x 4`.
   Example output:
   ```text
   Square area = 25
   Rectangle area = 20
   ```

6. Create `inline int toSeconds(int minutes)`. Return minutes multiplied by `60`. In `main()`, call it with `5`.
   Example output:
   ```text
   Seconds = 300
   ```
