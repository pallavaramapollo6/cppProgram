# C++ Programming Learning Pack

A beginner-friendly C++ programming repository with simple programs, practice tasks, and answer code. This learning pack is useful for students, self-learners, teachers, and lab instructors who want to learn or teach C++ programming step by step.

Created by **Krishnakumar**.

If you are learning C++, start from `01_basics` and continue folder by folder. If you are teaching C++, each program is small enough for classroom explanation, lab practice, assignments, and revision.

## Repository Structure

| Folder | Topics Covered |
| --- | --- |
| `01_basics` | Syntax, output, comments, data types, variables, input, constants, escape sequences, namespace |
| `02_operators` | Arithmetic, relational, logical, assignment, unary, ternary, bitwise, `sizeof`, type casting |
| `03_control_flow` | `if`, `if-else`, nested `if`, `switch`, loops, range-for, `break`, `continue`, `goto` |
| `04_functions` | Function types, recursion, reference parameters, overloading, default arguments, inline functions, lambdas |
| `05_arrays_strings` | Arrays, 2D arrays, strings, string methods, reverse, uppercase, lowercase, `getline` |
| `06_structures_pointers` | Structure, union, enum, pointers, pointer modification, pointer to pointer |
| `07_oop` | Class, object, constructors, destructor, encapsulation, inheritance, polymorphism, abstraction, friend function, operator overloading |
| `08_files_exceptions` | File write/read/append, file checking, binary files, exception handling |
| `09_stl` | Vector, list, set, map, stack, queue, sort, find, pair, iterator |
| `10_dynamic_memory_templates` | `new`, arrays, `malloc`, `calloc`, `realloc`, templates, static keyword, smart pointer, memory leak awareness |

## How To Compile And Run

Compile any single C++ file with `g++`:

```powershell
g++ path\to\file.cpp -o program.exe
.\program.exe
```

Example:

```powershell
g++ 01_basics\01_hello_world.cpp -o hello.exe
.\hello.exe
```

On Linux or macOS:

```bash
g++ path/to/file.cpp -o program
./program
```

## Suggested Learning Path

1. Learn syntax, variables, input, and output in `01_basics`.
2. Practice operators in `02_operators`.
3. Use `03_control_flow` to understand decisions and loops.
4. Move to functions, arrays, and strings.
5. Study structures, pointers, and object oriented programming carefully.
6. Finish with files, exceptions, STL, dynamic memory, and templates.
