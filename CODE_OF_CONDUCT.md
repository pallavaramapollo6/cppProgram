# Code Of Conduct

This project is made for students, teachers, and beginners. Everyone should feel welcome to learn, ask, improve, and contribute.

## Our Standards

Please help keep this repository friendly and useful by:

- Using respectful language.
- Giving helpful feedback.
- Being patient with beginners.
- Explaining suggestions clearly.
- Focusing on learning and improvement.

Unacceptable behavior includes insults, harassment, discrimination, spam, or intentionally harmful contributions.

## Reporting

If you see a problem in a discussion, issue, or pull request, please report it to the repository owner.

The goal of this project is simple: help more people learn programming with clear examples.
