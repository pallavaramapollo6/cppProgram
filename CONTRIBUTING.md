# Contributing

Thank you for wanting to improve this learning material.

This repository is made for students and teachers, so contributions should be simple, clear, and beginner-friendly.

## Ways To Contribute

- Add new simple programs.
- Improve comments and explanations.
- Add new practice questions.
- Add answers for practice tasks.
- Fix spelling, formatting, or code mistakes.
- Improve folder organization.
- Suggest better examples for classroom teaching.

## Contribution Guidelines

- Keep programs small and easy to understand.
- Use clear file names.
- Add comments where a beginner may need help.
- Do not make examples unnecessarily complex.
- Test the program before submitting.
- Keep the same folder style used in this repository.

## How To Submit

1. Fork the repository.
2. Create a new branch.
3. Add or improve the material.
4. Commit your changes with a clear message.
5. Open a pull request.

Every useful contribution matters. Even a small correction can help many students.
