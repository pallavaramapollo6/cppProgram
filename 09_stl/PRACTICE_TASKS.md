# C++ STL Practice Tasks

Follow each requirement exactly. Use the requested STL container or algorithm.

1. Create `vector<int> prices = {100, 250, 50}`. Use a range-based loop to calculate and print the total.
   Example output:
   ```text
   Total = 400
   ```

2. Create `vector<int> scores = {88, 45, 92, 70}`. Use `sort()` to arrange them in ascending order and print all values.
   Example output:
   ```text
   45 70 88 92
   ```

3. Create `set<int> rolls = {3, 1, 3, 2, 1}`. Print the set values to show duplicates are removed.
   Example output:
   ```text
   1 2 3
   ```

4. Create `map<string, int> prices`. Store `Pen = 10` and `Book = 50`, then print only the price of `Book`.
   Example output:
   ```text
   Book price = 50
   ```

5. Create `queue<string>` with `Anu`, `Ravi`, and `Meena`. Print and remove customers until the queue is empty.
   Example output:
   ```text
   Serving Anu
   Serving Ravi
   Serving Meena
   ```

6. Create `stack<int>` with `10`, `20`, and `30`. Print and remove values until the stack is empty, showing reverse order.
   Example output:
   ```text
   30 20 10
   ```
