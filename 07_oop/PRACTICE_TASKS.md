# C++ OOP Practice Tasks

Follow each requirement exactly. Use classes and access specifiers as requested.

1. Create a `Laptop` class with public members `brand`, `ram`, and `price`. Add a `display()` method. Store `Dell`, `8`, and `45000`, then display them.
   Example output:
   ```text
   Dell 8GB 45000
   ```

2. Create a `BankAccount` class with private `balance`. Add public `deposit(int amount)` and `display()` methods. Deposit `1000` and print the balance.
   Example output:
   ```text
   Balance = 1000
   ```

3. Create a `MovieTicket` class with private `movieName` and `seatNumber`. Use a parameterized constructor to store `Leo` and `25`, then print both values.
   Example output:
   ```text
   Leo Seat: 25
   ```

4. Create a `Message` class that declares `void show();` inside the class and defines `Message::show()` outside the class.
   Example output:
   ```text
   Method outside class
   ```

5. Create parent class `Teacher` with method `teach()`. Create child class `MathTeacher` with method `subject()`. Call both methods using a `MathTeacher` object.
   Example output:
   ```text
   Teaching
   Maths
   ```

6. Create a `Distance` class with private `meter`. Overload the `+` operator to add two `Distance` objects. Add `10` meters and `20` meters and print `30 meters`.
   Example output:
   ```text
   30 meters
   ```
